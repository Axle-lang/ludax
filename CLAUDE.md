# CLAUDE.md — ludax

**Ludax** is a game engine written in **Axle**: entities and worlds, physics, animation, audio, an asset pipeline
and a renderer whose lighting is meant to be provably right, on top of the platform library
[smalt](https://github.com/Axle-lang/smalt). Source is `src/**.axle`, config `axle.toml`. Read
`doc/ARCHITECTURE.md` before moving or adding a file, and `doc/STYLE.md` before writing one.

## Where code goes

Layers, bottom to top. A module imports from its own layer or below — never above, never a sibling feature layer.

| Layer | Directory | Holds |
|---|---|---|
| 1 | `src/core` | maths, memory, containers, ids, random, time, log, jobs, profiler, the test harness |
| 2 | `src/data` | assets, importers, serialisation |
| 3 | `src/world` | ECS, scenes, transforms, spatial indices |
| 4 | `src/sim` | physics (`kinetic`), animation, audio, navigation, gameplay |
| 5 | `src/render` | scene extraction, render graph, backends, lighting |
| 6 | `src/runtime` | main loop, game modules, settings |
| 7 | `src/voxel`, `src/openworld` | content modules; they never import each other |

## Rules of the code

- **Visibility is part of the design.** A declaration is private until something outside its file needs it; then
  `pub(crate)` for the library's own use; `pub` only for what a game may call. Every `pub` item has a `/** … */`
  comment that says what it is for, not how it works.
- **A file starts with a header** `// name — one line`, then a paragraph on what it owns and why. A file past about
  700 lines is doing two jobs: split it along the jobs.
- **No fixed-size array as a value** (`T[N]`): Axle 0.18.3 miscompiles writes through them. Vectors and matrices
  are scalar fields; bulk data is `T[]` from `malloc` or a container of ours.
- **Structures for what they are**: `struct` for plain data, copied; `class` for identity and state that changes;
  `enum` + `match` for a closed set of cases (never an `if` ladder over a tag); `trait` for a seam with several
  implementers; free `fn` for a computation with no state; `pub const` for a named number.
- **f32 on hot paths, f64 for positions in the world.** A float literal next to an `f32` is an `f64` in `let`: use the
  typed constants of `core/math/scalar` or `as f32`. No `sin`/`cos` from libm in code that must be deterministic.
- **Determinism is a feature**: no wall clock in the simulation, no iteration order that depends on a hash or a
  thread, random numbers from an explicit `Pcg32`.
- **No operator overloading in Axle**: operations are named methods (`a.plus(b)`). The forms that update a value
  in place are `mut self` methods named `…In` (`a.addIn(b)`): a struct passed as a `mut` parameter is a copy, so an
  out-parameter cannot work. f64 twins carry a `D` prefix/suffix and are generated by `tools/gen_math_f64.sh`
  from the f32 files: edit the f32 original, never a `d*.axle`.
- **Float literals next to `f32` are `f64`** (`x * 0.5`, `1.0 / x` fail in `let`): write `(0.5 as f32)`. Float
  division by zero traps, so every divide is guarded.
- **Method chains break at the dots**, one call per line; `axle fmt` keeps the layout canonical, so it is run
  on every source file.
- **Comments say why**, not what. No commented-out code. No `TODO` without a name and a reason.
- **Strings read out of a list are only borrowed from it**: copy before the list goes (`fresh`).
- **Top-level names are global to the package** (Axle 0.18.3): two files may not both declare `fn helper` or
  `const LIMIT`, whatever their directory (E0003). Give free functions and constants an area prefix
  (`jobsDrain`), or make them `static fn`s of a class.
- **A trait needs one implementor inside the library** (else E0605 when it is a parameter type), and a class
  cannot be stored in a trait-typed field (E0709): hold a concrete type or make the owner generic over it.
- **No `string` elements in our generic containers** (a generic `T[]` of strings double-frees on growth in
  0.18.3): use `StringInterner`/`StringMap`, or std `ArrayList<string>`. Contract violations on a container
  (bad index, `pop` on empty) abort; ask first with `has`/`isEmpty`/`getOr`.
- **Build for speed with `-O 3`**: the default `-O 1` is 3-4× slower. Pin the compiler (`axle --version`).

## Checks

```sh
axle fmt --check                  # formatting
cd tests && axle build -O 3 && ./target/tests    # every suite; exit status = number of failures
tools/examples.sh                 # builds every example and runs the ones that check themselves
```

Tests are Axle programs: one suite per area under `tests/src`, each a `pub class <Area>Suite` with
`static fn run(c : Checks)`; `main.axle` runs them all. A bug fixed gets a check that failed before the fix.
